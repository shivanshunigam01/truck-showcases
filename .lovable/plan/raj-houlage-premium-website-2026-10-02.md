# Raj Houlage premium website

## Goal
Build a complete, responsive one-page corporate website for Raj Houlage Pvt. Ltd. using only the supplied company facts and copy.

## Experience
- Create a cinematic truck-led opening with the supplied logo, a large editorial headline, route details, and quote/service actions.
- Use a charcoal, off-white, muted gray, and Raj red visual system with strong industrial typography, sharp grids, restrained borders, and subtle motion.
- Build all requested sections: introduction, company profile, services, fleet, transportation journey, industries, advantages, media showcase, vision, RK Group, statistics, quote form, contact, and footer.
- Add a sticky desktop navigation and an accessible animated mobile menu.
- Use real Unsplash truck/logistics photography throughout, with prominent truck imagery in the opening section. Use an image-based cinematic treatment if a reliable, production-safe video is unavailable.

## Interactions and responsiveness
- Add restrained reveal, parallax, image-zoom, route-line, counter, navigation, and menu animations while respecting reduced-motion settings.
- Make the page intentionally responsive at desktop, tablet, and mobile widths with large tap targets and layouts adapted for small screens.
- Provide client-side quote form validation and an honest success message that does not claim an email was sent.

## SEO and discoverability
- Add the supplied page title and description, Open Graph fields, Twitter card metadata, canonical home URL, semantic headings, useful image alt text, and Organization structured data.
- Add crawler-friendly robots settings.
- Defer a new sitemap file until a public site URL exists; the project currently has no published or custom domain, and inserting a preview URL would be incorrect.

## Technical details
- Keep TanStack Start routing and Tailwind v4.
- Add Framer Motion for the requested animation system and use Lucide icons already available.
- Keep company content in structured data and reusable components.
- Store the supplied logo through the project asset system.
- Verify the final page visually at desktop and mobile sizes, and check build/runtime diagnostics.
